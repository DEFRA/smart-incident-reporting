Use this service to report noise from waste facilities, industrial sites and farms.

This includes noise from:

  • rubbish tips
  • recycling centres
  • large industrial sites, factories or businesses (such as food processing plants)
  • farming activity, such as poultry or pig farming

There’s a different way to:

  • report noise in Scotland
  • report noise in Wales
  • report environmental problems in Northern Ireland

Report other types of noise

You cannot use this service to report noise from:

  • neighbours
  • local businesses like restaurants and cafés

Contact your local council to report noise from neighbours or local businesses.

Before you start

You’ll need to know:

  • where the noise is coming from
  • where you noticed it
  • when you noticed it

You only need to give your personal details if you’re happy to be contacted for more information.

You’ll need to give an email address if you want to:

  • send photos
  • get a reference number
